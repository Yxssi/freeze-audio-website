# Freeze Audio website

## Code style

- Do not add comments anywhere: no `//`, `/* */`, `<!-- -->`, `#` or JSDoc. The code must be clear and self-explanatory through names and structure.
- When something needs explaining, rename it or extract it instead of commenting it. Rationale and decisions belong in `docs/`.
- Keep only directives that tools read: the shebang in shell scripts and `// @ts-check` in `astro.config.mjs`.
