## Release 1.1.0 cut (2026-10-15)

Goal set by the owner: the site goes straight to the essentials and is no longer Mac-oriented.

- **Kept**: one-sentence description, screenshot, short features, downloads for both platforms, requirements, install steps per platform.
- **Removed**: Engines (5 long cards), Controls (8 parameters + presets table), Compat (Mac-only, "Audio Unit only", "no Windows"), FAQ (its answers were either Mac-only or now redundant: price sits in the hero, host-not-found is the rescan step, the security warnings sit in Install).
- **Merged**: Engines + Controls → one Features section (6 one-line modes, then Controls / Presets / Display). Compat → requirements inside each Download card.
- **Platform-neutral**: macOS and Windows are always shown side by side, macOS first only because of alphabetical order. The hero has two equal primary buttons that link straight to each installer; no OS detection script, to keep zero client JS and avoid guessing wrong. Each Download card offers the installer and the manual `.zip`.
- **Single source**: version, file names and `downloadsBaseUrl` live in `src/site.ts`; `src/downloads.ts` computes size and SHA-256 at build time and only warns when a file is missing, so the site builds before the binaries exist.
- **Hosting**: unchanged mechanism (static files under `public/downloads/`). The plugin repository is private, so no GitHub release links.
- **Trust counter**: SHA-256 checksums moved into a collapsed "SHA-256 checksums" disclosure under the download cards (rendered only when files are present).
- **Screenshot**: replaced by the 1.1.0 VST3 build in Freeze mode, EVERY 1/4 (`src/assets/freeze-ui.png`, 1400×880).
- **SEO**: titles and descriptions name both platforms and both formats; JSON-LD `operatingSystem: "macOS 12+, Windows 10/11"`, `softwareVersion: 1.1.0`, `downloadUrl` = both installers, `offers` price 0.

The audit tables below predate this cut; rows that point at removed sections (Compat, FAQ, Mac-only copy) are historical.
