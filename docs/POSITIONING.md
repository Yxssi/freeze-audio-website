## Brand Script (StoryBrand)

| SB7 element | Content |
|---|---|
| **1. Character (hero)** | A Mac producer/beatmaker mid-session. ONE desire: turn a moment they just heard in their track into a transition or texture — **now, while it's still alive**. |
| **2. Problem — External** | Making reverse swells, tape stops, frozen pads by hand: bounce the clip, reverse it, drag it back, nudge it into place. Every effect, every time. |
| **2. Problem — Internal** | **The moment is gone by the time the workaround is finished.** The sound in your head is alive; the editing kills it. *(Confirmed at Phase 5 exit — the emotional driver all copy leans on.)* |
| **2. Problem — Philosophical** | A moment of inspiration shouldn't die because your tools make you work like an editor instead of a musician. |
| **Villain** | The bounce-reverse-drag workaround. |
| **3. Guide — Empathy** | "The fragment you want is already behind the playhead." Copy names the workaround's cost, never blames the user. |
| **3. Guide — Authority** | Honest indie proof: Apple auval validation passed · tested in FL Studio · universal binary (Apple Silicon + Intel) · 219 KB · SHA-256 on page · free, no account. No fabricated numbers or testimonials (F7 stays an acquisition task). |
| **4. Plan — Process** | Already the on-page Install section: 1. Download the .zip · 2. Drop `Freeze.component` in `~/Library/Audio/Plug-Ins/Components` · 3. Relaunch your host. |
| **4. Plan — Agreement** | Free · no account · no price · uninstall = delete one file. |
| **5. CTA — Direct** | **Download Freeze 1.0.0 — Free** (hero, download section) / **Download** (nav, footer). |

| **7. Success** | The sound in your head comes out of the speakers seconds after you think it — frozen, reversed, stretched, live while the track plays. |

## One-Liner

**Chosen (repeat-after-one-hearing test, confirmed 2026-10-09):**

> **Freeze is a free Mac plugin that captures the last seconds of your track and plays them back backwards, frozen, or stretched — so you make transition effects live instead of editing them by hand.**

Formula: [problem: manual editing] + [solution: rolling memory, five engines] + [result: live transitions]. Use in: meta-description direction, launch copy, store/social bios, future "About" copy. FR launch usage: derive from it, don't translate word-for-word.
